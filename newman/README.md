# Newman Reports

Generated API test reports are written to `newman/reports/`.

The runner uses:

- `postman/Education Platform API.postman_collection.json`
- `postman/Education Platform Local.postman_environment.json`

## Outputs
- `education-platform-api.junit.xml`
- `education-platform-api.html`

These files are created by `npm run test:api` and `npm run test:api:html`.
